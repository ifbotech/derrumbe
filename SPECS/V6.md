## 2. Celdas

### Celda: reglas-balance
Eres Reglas-Balance. Lee `.claude/agents/reglas-balance.md`. Sala: `Reglas-Balance`. Solo tocas `src/rules/`, `scripts/analyze-meta.ts`, `scripts/lab.ts`, `scripts/meta-report.json` y `tests/`.

1. Reescribe `src/rules/tutorial.ts` como una lista de **hitos verificables** de la obra 1: primer golpe, primera carta de palo inmune, primer golpe limpio, primera sirena, primer colapso. Cada hito es una función pura `(view, events) => boolean` con un identificador estable que la interfaz usa para decidir qué pista mostrar y cuándo retirarla. Añade `nextHint(view, seen): HintId | null`, que devuelve la siguiente pista o `null` si el jugador ya hizo el hito sin ayuda.
2. Quita del guion lo que ya no hace falta (los pasos obligatorios que bloqueaban la mesa): una versión no añade sistema sin retirar otro.
3. Añade al laboratorio (`analyze-meta.ts`) un bot «novato» que solo sigue `nextHint` y elige la jugada resaltada. Informa la victoria de la obra 1. Objetivo: ≥ 90 %.
4. Pruebas en `tests/tutorial.test.ts`: cada hito se dispara con una partida sembrada, `nextHint` no repite un hito cumplido y el guion no cambia el resultado de ninguna jugada (semilla + acciones reproducen la partida).
5. No cambies números de balance de las obras 2 a 8.

Comprobación, en orden: `npm run typecheck`, `npm test`, `LAB_HILOS=6 npm run analyze:meta -- foco`, informe completo al final y `npm run docs`. Informe: hitos, medida del bot novato con su n, y qué datos expones.
