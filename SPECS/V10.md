# V10 · Congelación de funciones y pulido de candidata a lanzamiento

Estado: planificada. Se ejecuta con `scripts/estudio-autonomo.ps1` sobre la rama `estudio/v10`, con las celdas en el orden en que aparecen. **Congelación**: ninguna celda añade una función.

## 1. Tema y evidencia

**Tema.** Cero funciones nuevas: defectos, rendimiento, accesibilidad y textos.

| Evidencia | Número | Fuente |
|---|---|---|
| Auditoría visual | 76 revisiones (19 estados × 4 ventanas) con problemas P0/P1/P2 por pantalla | auditorías por pantalla |
| Constitución | ≤ 6 palabras clave, ≤ 56 herramientas, descripciones ≤ 115, P95 ≤ 19 | `tests/invariantes.test.ts` |
| Fatiga a las 4 h | objetivo de la V8: `riesgo_fatiga_4h` ≤ 4 | puerta de GPU de la V8 |
| Ruido del panel | ±6 puntos de aprobación con n = 240 | INFORME_EJECUTIVO |
| Objetivos | 60 fotogramas por segundo; lo animado solo cambia `transform` y `opacity` | reglamento de arte-ui |

## 2. Celdas

### Celda: reglas-balance
Eres Reglas-Balance. Lee `.claude/agents/reglas-balance.md`. Sala: `Reglas-Balance`. Solo tocas `src/rules/`, `scripts/analyze-meta.ts`, `scripts/lab.ts`, `scripts/meta-report.json` y `tests/`.

1. **Congelación**: escribe en `tests/invariantes.test.ts` una comprobación contra una lista de identificadores guardada (herramientas, especiales, jefes, palabras clave, niveles): si la V10 añade o quita alguno, la prueba falla. La lista se genera con la V9.
2. **Revisión de textos de reglas**: ortografía, tono y jerga en `desc` de herramientas, especiales, jefes, niveles, contratos y sellos. Cambia solo el texto, nunca un número. Descripciones ≤ 115 caracteres.
3. **Errores**: corre las seis barajas con 1 a 4 jugadores en `scripts/simulate*.ts` con miles de semillas y reporta cualquier excepción o estado inalcanzable. Arregla lo que sea del motor.
4. **Balance final**: informe completo (`LAB_HILOS=6 npm run analyze:meta`) sin avisos y `npm run docs`.

Comprobación: `npm run typecheck`, `npm test`, informe sin avisos. Informe: excepciones halladas y arregladas, cambios de texto.

### Celda: arte-ui
Eres Arte-UI. Lee `.claude/agents/arte-ui.md`. Sala: `Arte-UI`. Eres dueño de `theme.css`, `styles.css`, `campaign.css`, `card.ts`, `art.ts`, `glyphs.ts`, `engraving.ts`, `table.ts`, `runscreens.ts`, `guild.ts`, `widgets.ts`, `home.ts`, `lobby.ts`, `lupa.ts`, `scripts/visual-qa.ts` y `qa.ts`.

1. **Barrido de los 19 estados × 4 ventanas**: cero P0 y P1 abiertos en la QA visual. Mira cada captura y anota los P2 que no arregles, con motivo.
2. **Accesibilidad**: nombres accesibles y roles (`button`, `dialog`, `status`) en todos los controles, orden de tabulación coherente con la lectura, `prefers-reduced-motion` respetado, contraste AA (4,5:1) en todo texto y ≥ 7:1 en números críticos y palos sobre crema. La QA añade una comprobación de nombre accesible por control.
3. **Textos de interfaz**: revisión de ortografía y tono en `rules-text.ts`, `flavor.ts` y las pantallas. Cambia solo texto, no estructura.
4. **Rendimiento visual**: ninguna animación de `top`, `left`, `width` ni filtros; solo `transform` y `opacity`.

No añadas pantallas ni estados de juego. Comprobación: `npm run typecheck` y `QA_DIR=dist/qa-arte npm run qa:visual` con cero fallos dos veces seguidas; mira las capturas.

## 3. Criterios de aceptación

| # | Criterio | Orden |
|---|---|---|
| 1 | Cero diferencias en herramientas, especiales, jefes, palabras clave y niveles respecto a la V9 | `npm test` |
| 2 | Cero P0 y P1 en 19 estados × 4 ventanas, dos corridas seguidas | `npm run qa:visual` |
| 3 | Todo control tiene nombre accesible; contraste AA | `npm run qa:visual` |
| 4 | Humo en verde dos corridas seguidas; foco nunca atrapado | `npm run qa:smoke` |
| 5 | Informe del laboratorio sin avisos; P95 ≤ 19 | `npm run analyze:meta` |
| 6 | Aprobación por persona sin bajar del ruido respecto a la V9 | puerta de GPU |

## 4. Fuera de alcance

Cualquier función, herramienta, jefe, nivel, palabra clave o sistema nuevo; cualquier cambio de un número de balance; cambios de protocolo del cooperativo. Lo que no quepa se anota como «pendiente para una versión posterior» y no se mete.
